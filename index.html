Kelola Catatan Kas, Laba/Minus & Rincian Saldo Secara Otomatis.

Aplikasi pembukuan kas harian dengan sistem Running Balance (Saldo Berjalan). Setiap transaksi otomatis menghitung Saldo Awal dari baris sebelumnya, menjumlahkan rincian sub-item Saldo Masuk & Saldo Keluar, hingga menampilkan status Laba/Minus dan Total Saldo secara instan.

3. Saldo Keluar (-) - Rp 1.250.000 2 Rincian Pengeluaran

STATUS: LABA
5. Total Saldo Akhir (Saldo Awal + Laba/Minus) Rp 12.250.000
Keunggulan Sistem

Dirancang Khusus untuk Pembukuan Rinci

Tidak perlu lagi menghitung rumus manual di kertas atau khawatir urutan saldo berantakan saat mengedit transaksi.

Saldo Awal Berantai Otomatis

Setiap baris otomatis mengambil Total Saldo dari transaksi sebelumnya sebagai Saldo Awal. Jika Anda mengedit atau menyisipkan tanggal lama, seluruh urutan dihitung ulang otomatis.

Kalkulator Rincian Sub-Item

Satu tanggal punya banyak nota? Tambahkan sub-item + Saldo Masuk maupun - Saldo Keluar beserta Qty dan harga satuan. Totalnya langsung terakumulasi.

Proteksi Admin & Siap Cloud

Dilengkapi halaman login Admin dengan password yang bisa Anda ganti kapan saja, fitur Backup/Restore JSON, Ekspor CSV Excel, dan sinkronisasi Google Apps Script.

Struktur Tabel Standar

Format 7 Kolom Inti Pembukuan Kas

1. Tanggal Urutan kronologis & nomor baris
2. Keterangan Judul & tombol buka tabel rincian item
3. Saldo Awal Saldo sebelum transaksi baris tersebut
4. Saldo Masuk Total uang masuk (+) pada baris itu
5. Saldo Keluar Total uang keluar (-) pada baris itu
6. Laba / Minus Selisih Masuk dikurangi Keluar
7. Total Saldo Saldo Awal + Laba/Minus
Siap Online Gratis

Bisa Dipasang di GitHub Pages maupun Google Apps Script (GAS)

File ini sudah dilengkapi jembatan otomatis (google.script.run). Jika Anda menaruhnya di GitHub Pages, data tersimpan aman di browser. Jika Anda memasangnya di Google Apps Script, Anda bisa menekan tombol Sinkron Cloud di dashboard untuk menyimpan & mengambil data langsung dari Google Sheets!
